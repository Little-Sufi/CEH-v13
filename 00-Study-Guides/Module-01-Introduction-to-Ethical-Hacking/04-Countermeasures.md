## 🏰 1. Defense-in-Depth Layered Architecture

> [!SHIELD] 🏰 **📋 Comprehensive Defense-in-Depth Layered Architecture Reference Matrix**

| Security Layer | Primary Protective Focus | Core Technical Controls & Countermeasures |
| :--- | :--- | :--- |
| **Policies & Procedures** | Administrative Security Governance | Information Security Policy, Employee NDAs, Incident Response Plans |
| **Physical Security** | Facility & Asset Protection | Biometric Locks, Security Guards, CCTV, Mantraps, Badge Scanners |
| **Perimeter Defense** | Edge Network Boundary | Firewalls, WAF, DDoS Scrubbing, Border Routers, VPN Gateways |
| **Internal Network** | Segmented Subnets & VLANs | Internal Firewalls, Network Access Control (NAC), IDS/IPS, Microsegmentation |
| **Host Security** | Server & Endpoint Defense | Endpoint Detection & Response (EDR), OS Patching, Antivirus, Hardening |
| **Application Layer** | Software & Web Application | Secure Coding Standards, Input Validation, WAF Rules, Code Reviews |
| **Data Layer** | Critical Information Assets | AES-256 Storage Encryption, Data Loss Prevention (DLP), Database Auditing |

## 🛡️ 2. Risk Management Formulas & Calculations

- **Single Loss Expectancy (SLE)**: $SLE = Asset\ Value\ (AV) \times Exposure\ Factor\ (EF)$
- **Annualized Loss Expectancy (ALE)**: $ALE = SLE \times Annualized\ Rate\ of\ Occurrence\ (ARO)$
