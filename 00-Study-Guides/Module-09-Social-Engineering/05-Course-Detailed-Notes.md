## 📌 1. Reverse Social Engineering & Identity Theft

### 1.1 Reverse Social Engineering Lifecycle
In a Reverse Social Engineering attack, the attacker manipulates the victim into contacting the attacker first for assistance.

#### 3 Phases of Reverse Social Engineering:
1. **Sabotage**: Attacker secretly causes a technical problem on the target system (e.g., corrupting a network driver or crashing a service).
2. **Advertising**: Attacker advertises themselves as an expert who can fix the problem (e.g., dropping fake tech support business cards or sending pop-up error notices).
3. **Assistance**: The victim calls the attacker for assistance. The attacker "helps" the victim while extracting administrative passwords or installing persistent backdoors.

| Phase Number | Phase Name | Attacker Action | Victim Behavior |
| :---: | :--- | :--- | :--- |
| **Phase 1** | **Sabotage** | Induces system crash or network failure | Experiences system malfunction |
| **Phase 2** | **Advertising** | Leaves fake support numbers / emails | Searches for technical assistance |
| **Phase 3** | **Assistance** | Requests credentials to "fix" the issue | Voluntarily hands over passwords |
