## 🛠️ 1. Primary Software Reference Matrix

> [!TOOL] 📋 **Comprehensive Session Hijacking Tools Reference Matrix**

| Software Name | Operational Category | Primary Technical Feature | Supported Platform |
| :--- | :--- | :--- | :--- |
| **Ettercap** | MitM / Session Sniffer | ARP poisoning, packet filtering, credential harvesting | Linux, Windows |
| **Bettercap** | Modular MitM Framework | Modern ARP/DNS spoofing, HTTPS proxy, cookie stealing | Cross-platform |
| **Hunt** | TCP Session Hijacker | TCP sequence prediction and connection takeover | Linux |
| **Hamster & Ferret** | Automated Cookie Sniffer | Captures wireless cookies and automatically logs into sessions | Linux |
| **Cookie Editor** | Browser Extension | Allows manual viewing, modifying, and importing session cookies | Firefox, Chrome |
| **tcpkill** | Network Utility | Sends spoofed TCP RST packets to kill active connections | Linux |
