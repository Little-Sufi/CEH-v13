## 🛠️ 1. Primary Web Server Testing Software Matrix

> [!TOOL] 📋 **Comprehensive Web Server Hacking Tools Reference Matrix**

| Software Name | Operational Category | Primary Technical Capability | Supported Platform |
| :--- | :--- | :--- | :--- |
| **Nikto** | Web Vulnerability Scanner | Scans 6700+ dangerous files/CGIs, outdated server software | Cross-platform |
| **Davtest** | WebDAV Vulnerability Scanner | Tests DAV enabled servers by uploading test files | Linux |
| **Cadaver** | WebDAV CLI Client | Interactive CLI client for uploading/editing WebDAV files | Linux |
| **WPScan** | WordPress Security Scanner | Enumerates WP plugins, themes, users, and vulnerable scripts | Linux |
| **Burp Suite** | Web Application Proxy | Intercepts HTTP/S requests, fuzzes headers, manipulates requests | Cross-platform |
| **Nmap HTTP Scripts**| Port & Script Scanner | `--script=http-enum`, `http-config-backup`, `http-vhosts` | Cross-platform |
