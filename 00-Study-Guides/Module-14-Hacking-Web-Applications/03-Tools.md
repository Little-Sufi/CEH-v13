## 🛠️ 1. Primary Web Application Testing Tools Matrix

> [!TOOL] 📋 **Comprehensive Web Application Hacking Tools Reference Matrix**

| Software Name | Operational Category | Primary Technical Capability | Supported Platform |
| :--- | :--- | :--- | :--- |
| **Burp Suite** | Web Application Proxy | HTTP intercept, Repeater, Intruder, Vulnerability Scanner | Cross-platform |
| **OWASP ZAP** | Open-source Web Proxy | Automated vulnerability scanner, active/passive scanner | Cross-platform |
| **Ffuf / Gobuster** | Web Directory Fuzzer | High-speed directory, parameter, and VHost fuzzing | Cross-platform |
| **Nuclei** | Template-driven Scanner | Fast vulnerability scanning based on community YAML templates | Cross-platform |
| **Postman** | API Testing Suite | Formulates and tests REST/SOAP/GraphQL API requests | Cross-platform |
| **OWASP Dep-Check** | SCA Dependency Scanner | Detects known vulnerable components in software dependencies | Cross-platform |
