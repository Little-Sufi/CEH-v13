## 🛠️ 1. Primary SQL Injection Tools Reference Matrix

> [!TOOL] 📋 **Comprehensive SQL Injection Testing Tools Matrix**

| Software Name | Operational Category | Primary Technical Capability | Supported Platform |
| :--- | :--- | :--- | :--- |
| **SQLmap** | Automated SQLi Suite | Full DB enumeration, OS shell access, tamper scripts | Cross-platform |
| **jSQL Injection** | Java-based GUI | Automated SQL injection testing and database dumping | Cross-platform |
| **Havij** | Windows Automated GUI | Automated SQL injection scanner and data extractor | Windows |
| **BBQSQL** | Blind SQLi Framework | Semi-automatic blind SQL injection exploitation tool | Linux |
| **Burp Suite** | Application Proxy | Manual payload injection, SQLi fuzzing via Intruder | Cross-platform |
