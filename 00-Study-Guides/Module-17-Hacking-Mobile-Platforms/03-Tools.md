## 🛠️ 1. Primary Mobile Hacking Tools Reference Matrix

> [!TOOL] 📋 **Comprehensive Mobile Application Security Tools Matrix**

| Software Name | Category | Primary Technical Capability | Supported Platform |
| :--- | :--- | :--- | :--- |
| **MobSF (Mobile Security Framework)** | Automated Mobile Scanner | Static and dynamic security auditing of APK, IPA, and source code | Cross-platform |
| **Jadx** | Java Decompiler | Converts Android DEX bytecode into readable Java source code | Cross-platform |
| **Apktool** | APK Reverse Engineering | Decodes APK resources to original form and rebuilds modified code | Cross-platform |
| **Frida** | Dynamic Instrumentation | Injects JavaScript engine into native app processes for runtime hooking | Cross-platform |
| **Objection** | Mobile Runtime Auditor | Powered by Frida; bypasses SSL pinning, inspects storage without root | Cross-platform |
| **ADB (Android Debug Bridge)** | Mobile CLI Debugger | Versatile command-line tool to communicate with Android emulator/device | Cross-platform |
