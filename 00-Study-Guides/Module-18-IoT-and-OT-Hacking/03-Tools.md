## 🛠️ 1. Primary IoT & OT Testing Tools Matrix

> [!TOOL] 📋 **Comprehensive IoT & OT Hacking Software & Hardware Matrix**

| Tool / Hardware Name | Category | Primary Technical Capability | Supported Platform |
| :--- | :--- | :--- | :--- |
| **Binwalk** | Firmware Analysis | Analyzes and extracts embedded filesystems from binary blobs | Linux |
| **Bus Pirate** | Hardware Debugging | Multi-protocol hardware interface (UART, SPI, I2C, JTAG) bridge | Hardware |
| **JTAGulator** | Pinout Identification | Assists in identifying JTAG and UART pinouts on target PCBs | Hardware |
| **Shodan** | Internet Search Engine | Discovers publicly exposed IoT devices, ICS PLCs, and SCADA HMIs | Cloud |
| **Mosquitto CLI** | MQTT Client | CLI tool (`mosquitto_pub`/`mosquitto_sub`) to publish/subscribe to MQTT | Cross-platform |
| **Ghidra / IDA Pro** | Firmware Disassembler | Reverses compiled MIPS, ARM, and Xtensa IoT CPU binaries | Cross-platform |
