## 🛠️ 1. Primary Cryptography Security & Auditing Tools Matrix

> [!TOOL] 📋 **Comprehensive Cryptography Tools Matrix**

| Software Name | Category | Primary Technical Capability | Supported Platform |
| :--- | :--- | :--- | :--- |
| **OpenSSL** | Cryptographic Library CLI | Key generation, SSL/TLS testing, file encryption/decryption | Cross-platform |
| **VeraCrypt** | Disk Encryption | Open-source full disk & container encryption using AES, Twofish, Serpent | Cross-platform |
| **Hashcat** | Password Hash Cracker | GPU-accelerated hash cracking supporting 300+ hash algorithms | Cross-platform |
| **Steghide** | Steganography Tool | Hides and extracts embedded data in JPEG, BMP, WAV, and AU files | Linux / Windows |
| **CrypTool** | E-Learning Cryptanalysis | Interactive GUI tool for studying cryptographic algorithms & attacks | Windows / Web |
| **CyberChef** | Cyber Swiss Army Knife | Web app for encoding, decoding, hashing, and encryption operations | Web Browser |
