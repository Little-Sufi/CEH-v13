## 📝 Key AD Concepts

| Term | Description |
|------|-------------|
| Domain | Logical group of objects |
| Domain Controller (DC) | Server that manages AD |
| OU | Organizational Unit - groups objects |
| Group | Collection of users/computers |
| Forest | Collection of domains |
| Tree | Collection of domains in hierarchy |
