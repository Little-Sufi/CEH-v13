## 🎯 Objective
Configure the Social-Engineer Toolkit (SET) on Kali Linux to create a local testing listener.

## 📝 Commands
```bash
# Install and run SET
sudo apt update && sudo apt install set -y
sudo setoolkit
```
In the menu:
- Select option `1` (Social-Engineering Attacks)
- Select option `2` (Website Attack Vectors)
