## 🎯 Objective
Deploying Gophish to manage simulated phishing audits.

## 📝 Commands
```bash
# Download and extract Gophish
wget https://github.com/gophish/gophish/releases/download/v0.12.1/gophish-v0.12.1-linux-64bit.zip
unzip gophish-v0.12.1-linux-64bit.zip
chmod +x gophish
sudo ./gophish
```
Navigate to `https://127.0.0.1:3333` to set up target lists, templates, and track open rates.
